# Review Implemented Plan

This skill exists as a compatibility alias for older wording.

## Use in this workspace

Prefer **`@implementation-review`** for the actual workflow.

The intended behavior is:
- compare implemented work against a concrete plan
- verify the real behavior as narrowly as possible
- report only meaningful findings backed by evidence
- avoid speculative or style-only commentary
