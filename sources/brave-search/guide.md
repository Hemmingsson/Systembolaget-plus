# Brave Search

Brave Search provides web and local search capabilities through an MCP server.

## Scope

Use this source when you need:
- general web search results from Brave
- local/business discovery queries
- lightweight research inside MCP workflows
- a dedicated search tool separate from browser automation

## Guidelines

- Use Brave Search for fast search retrieval and structured result sets
- Prefer precise queries with location or freshness hints when relevant
- Local search is useful for places, venues, and nearby businesses
- For deep page extraction, combine results with direct fetch or browser tools

## Examples

- Search for recent documentation on an npm package release
- Find local businesses or addresses for a given city
- Gather search results before opening specific pages in the browser
