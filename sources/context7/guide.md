# Context7

Context7 provides up-to-date, version-aware library documentation and code examples for coding and integration tasks.

## Scope

Use this source when you need:
- current package or framework documentation
- version-specific API references
- code examples grounded in current docs rather than model memory
- library lookup and documentation retrieval during implementation work

## Guidelines

- Prefer Context7 when a task depends on framework, SDK, or package details
- Use it to resolve library identifiers before requesting documentation
- Treat Context7 as a documentation source, not a package manager or code executor
- If a library is missing or sparse, fall back to official docs or web verification

## Examples

- Resolve the library id for React Router and fetch the latest docs
- Look up Next.js middleware docs before editing auth logic
- Pull current Netlify or MCP package documentation during setup work
